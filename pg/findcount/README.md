# 글자 찾기 개수 세기

화면에 흩어진 글자 중 예시된 글자를 찾아 개수를 세는 **인지훈련 학습지**를 생성·인쇄하는
도구입니다.

- 사용: [https://yonzi0510.github.io/work/pg/findcount/](https://yonzi0510.github.io/work/pg/findcount/) 접속
- 인터넷 없이도 동작합니다 (파일 하나로 실행).

## 사용 순서

1. **대상 글자 묶음** 선택 — 기초 글자(가나다라마바사아) / 자음(ㄱㄴㄷㄹㅁㅂㅅㅇ) / 숫자(1~8)
2. **난이도**(1~5단계) 선택 — 단계가 올라갈수록 대상 글자 수·등장 횟수가 늘고, 예시에 없는
   "가짜 글자"가 섞이고, 글자가 살짝 기울어집니다. **글자 칸 크기는 모든 단계에서 항상 크게
   고정**되어 있어 난이도가 올라가도 글자가 작아지지 않습니다.
3. **생성** → **인쇄/PDF 저장**

매번 [생성]을 누르면 흩어진 배치가 새로 만들어집니다.
