# 글귀필사 워크북

인지훈련용 **좋은 글귀(속담·명언 / 계절·자연 / 마음·감사) 필사 학습지**를 생성·인쇄하는
도구입니다. 특정 종교와 무관한 내용만 담았습니다. 방식은 [성결필사 워크북](../pilsa/)과 같습니다:
원고지 한 줄을 연한 안내 글씨로 보여준 바로 아래에 그 줄만 따라 쓰게 한 뒤 다음 줄로 넘어가서,
전체 문장을 외우지 않아도 눈앞의 한 줄만 보고 옮겨 쓸 수 있습니다.

- 사용: [https://yonzi0510.github.io/work/pg/geulgwi/](https://yonzi0510.github.io/work/pg/geulgwi/) 접속
- 인터넷 없이도 동작합니다 (파일 하나로 실행).

## 사용 순서

1. **글귀 선택** — 속담·명언 / 계절·자연 / 마음·감사 중 원하는 것만 체크 (전체 선택/해제 가능)
2. 필요하면 **글귀 직접 입력**란에 `구분 | 본문` 형식으로 한 줄씩 추가
3. **인쇄 설정** — 글자 칸 크기(보통/크게/아주 크게), 한 줄당 따라쓰기 횟수(1~5회),
   원문 안내 표시 여부, 이름·날짜·확인란 표시 여부 선택
4. **생성** → **인쇄/PDF 저장**

글귀가 길면 자동으로 다음 장에 이어서 출력됩니다.

Day:음 (dayeum.co.kr) 부속 도구.
