# 한글 기초 쓰기 워크북

인지저하가 심한 어르신도 쓰실 수 있도록 **자음·모음·기초 글자(가나다라)·숫자(1~100)**를
아주 큰 글자로 연습하는 도구입니다. ㄱㄴㄷㄹ…처럼 한 줄에 순서대로 이어서 안내한 뒤,
바로 아래 같은 자리에 빈 줄을 이어 붙여 따라 쓰게 합니다.

- 사용: [https://yonzi0510.github.io/work/pg/hangeul/](https://yonzi0510.github.io/work/pg/hangeul/) 접속
- 인터넷 없이도 동작합니다 (파일 하나로 실행).

## 사용 순서

1. **내용 선택** — 자음(14자)·모음(10자)·기초 글자(가나다라~하, 14자)·숫자쓰기(1~10 … 91~100,
   10구간) 중 원하는 것만 체크 (전체 선택/해제, 숫자쓰기만 선택 버튼 제공)
2. **따라쓰기 줄 수**(2~5줄) 선택
3. **생성** → **인쇄/PDF 저장** (A4 가로 방향)

Day:음 (dayeum.co.kr) 부속 도구.
