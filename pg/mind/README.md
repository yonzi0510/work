# 오늘의 마음 살피기

우울감이 있는 어르신을 위한 **감정 체크인 활동지**입니다. 오늘 느낀 마음에 이름을 붙이고,
몸 어디에서 느껴지는지·그 마음에게 한마디 건넨다면 무엇인지 적어본 뒤, 마음의 온도(0~10)를
표시합니다.

- 사용: [https://yonzi0510.github.io/work/pg/mind/](https://yonzi0510.github.io/work/pg/mind/) 접속
- 인터넷 없이도 동작합니다 (파일 하나로 실행).

## 사용 순서

1. **글자 크기**(보통/크게) 선택
2. **인쇄/PDF 저장** — 매일 한 장씩 인쇄해서 나눠드리는 용도입니다. 날짜는 오늘 날짜로 자동
   채워지며 직접 수정할 수 있습니다.

Day:음 (dayeum.co.kr) 부속 도구.
