# 끝말잇기 활동지

시작 단어에서 이어서 끝말잇기를 채우는 **인지훈련 활동지**를 생성·인쇄하는 도구입니다.

- 사용: [https://yonzi0510.github.io/work/pg/kkeutmal/](https://yonzi0510.github.io/work/pg/kkeutmal/) 접속
- 인터넷 없이도 동작합니다 (파일 하나로 실행).

## 사용 순서

1. **난이도**(1~5단계) 선택 — 단계가 올라갈수록 시작 단어가 길어지고, 이어서 채울 빈 칸 수와
   문항 수가 늘어납니다.
2. **생성** → **인쇄/PDF 저장**

매번 [생성]을 누르면 시작 단어가 40개 단어은행에서 새로 무작위 선택됩니다.

Day:음 (dayeum.co.kr) 부속 도구.
