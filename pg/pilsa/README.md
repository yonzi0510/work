# 성결필사 워크북

인지훈련용 **성경 구절(거룩·성결 주제) 필사 학습지**를 생성·인쇄하는 도구입니다.
원고지 칸에 원문을 연한 안내 글씨로 보여준 뒤, 같은 칸 수의 빈 줄을 이어 붙여 따라 쓰게 합니다.

- 사용: [https://yonzi0510.github.io/work/pg/pilsa/](https://yonzi0510.github.io/work/pg/pilsa/) 접속
- 인터넷 없이도 동작합니다 (파일 하나로 실행).

## ⚠️ 사용 전 꼭 확인하세요

기본으로 담겨 있는 구절 본문은 참고용 예시입니다. 번역본(개역개정 등)에 따라 표기가 다를 수 있으니,
**인쇄해서 나눠드리기 전에 반드시 실제 사용하시는 성경과 대조 확인**해 주세요. 확인한 구절만 체크하거나,
"구절 직접 입력"란에 직접 확인한 본문을 붙여넣어 쓰면 더 안전합니다.

## 사용 순서

1. **구절 선택** — 기본 제공 구절 중 원하는 것만 체크 (전체 선택/해제 가능)
2. 필요하면 **구절 직접 입력**란에 `출처 | 본문` 형식으로 한 줄씩 추가
3. **인쇄 설정** — 글자 칸 크기(보통/크게/아주 크게), 따라쓰기 연습 횟수(1~5회),
   원문 안내 표시 여부, 이름·날짜·확인란 표시 여부 선택
4. **생성** → **인쇄/PDF 저장**

구절이 길면 자동으로 다음 장에 이어서 출력됩니다.

Day:음 (dayeum.co.kr) 부속 도구.
