# 숫자쓰기 워크북

인지저하가 심한 어르신도 쓰실 수 있도록 **숫자 1~100**을 아주 큰 글자로 연습하는 도구입니다.
1-2-3…처럼 한 줄(10칸)에 순서대로 이어서 안내한 뒤, 바로 아래 같은 자리에 빈 줄을 이어
붙여 따라 쓰게 합니다. 한글 자음·모음·기초 글자 연습은 [한글 기초 쓰기 워크북](../hangeul/)에
따로 있습니다.

- 사용: [https://yonzi0510.github.io/work/pg/number/](https://yonzi0510.github.io/work/pg/number/) 접속
- 인터넷 없이도 동작합니다 (파일 하나로 실행).

## 사용 순서

1. **내용 선택** — 1~10, 11~20 … 91~100 중 원하는 구간만 체크 (전체 선택/해제 가능. 기본은
   1~10만 체크됨)
2. **따라쓰기 줄 수**(2~5줄) 선택
3. **생성** → **인쇄/PDF 저장** (A4 가로 방향)

Day:음 (dayeum.co.kr) 부속 도구.
