# 천자문쓰기 워크북

인지훈련용 **천자문 쓰기 연습지**를 생성·인쇄하는 도구입니다. 천자문 전체 1000자(10권 × 25구 ×
4자, 훈음 포함)를 담았습니다. 서식은 실제 천자문 학습교재를 그대로 재현했습니다:
A4 가로 방향, 한 줄 12칸(모범 글자 1칸 + 따라쓰기 11칸) 격자에 훈음을 글자 칸 안쪽에 표시합니다.
한 구(4자)마다 한 장씩 인쇄됩니다.

- 사용: [https://yonzi0510.github.io/work/pg/cheonja/](https://yonzi0510.github.io/work/pg/cheonja/) 접속
- 인터넷 없이도 동작합니다 (파일 하나로 실행).

## 사용 순서

1. **권 선택** — 1권~10권 중 원하는 권만 체크 (전체 선택/해제 가능, 권마다 25구·100자)
2. **생성** → **인쇄/PDF 저장** (A4 가로 방향)

Day:음 (dayeum.co.kr) 부속 도구.
